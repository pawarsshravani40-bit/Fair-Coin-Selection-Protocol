    Experiment E: Modulo Bias vs Rejection Sampling

    Explains and empirically demonstrates why naive val % n produces unfair probabilities when the random number space is not divisible by n, and how Fair Pick's rejection sampling achieves uniform fairness.

    Mathematical Cause of Modulo Bias

    When generating a random 64-bit integer \(V \in [0, 2^{64}-1]\), the range size is \(2^{64} = 18,446,744,073,709,551,616\).
    If \(2^{64}\) is not divisible by \(n\) (e.g. for \(n=3, 5, 6, 7, 10\)), the remainder \(2^{64} \pmod n\) leaves the lower buckets with one extra possibility than the upper buckets.

    Fair Pick Cutoff Formula

    \(L = 2^{64} - (2^{64} \pmod n)\)

    If \(V < L\), accept \(V \pmod n\).
    If \(V \ge L\), reject \(V\), re-hash \(V\) via SHA-256, and test the next candidate. This ensures every outcome in \([0, n-1]\) has identical probability.

    Note: This is an empirical demonstration comparing finite sample distributions; not a substitute for mathematical proofs.
