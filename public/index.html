    PROTOCOL OVERVIEW

    How Fair Pick works

    The server coordinates the phases; each browser can independently verify the completed public audit.

    1. 01

      Commit

      Each participant creates a private random contribution in their browser and submits only its SHA-256 commitment.

    2. 02

      Lock

      After all required commitments arrive, the commitment set is locked before the reveal phase.

    3. 03

      Reveal

      Participants submit the same contributions. The server verifies them against the locked commitments and applies its reveal deadline.

    4. 04

      Select and verify

      Valid contributions are combined with XOR and used by 64-bit rejection sampling. Browsers then independently check the audit and announced selection.

    This commit–reveal design has limits: a participant who withholds a reveal can affect whether a round completes. The server enforces a deadline and aborts if fewer than two valid reveals remain. Fairness also assumes at least one unpredictable, honest contribution.

    Experiment E: Modulo Bias vs Rejection Sampling

    Explains and empirically demonstrates why naive val % n produces unfair probabilities when the random number space is not divisible by n, and how Fair Pick's rejection sampling achieves uniform fairness.

    Mathematical Cause of Modulo Bias

    When generating a random 64-bit integer \(V \in [0, 2^{64}-1]\), the range size is \(2^{64} = 18,446,744,073,709,551,616\).
    If \(2^{64}\) is not divisible by \(n\) (e.g. for \(n=3, 5, 6, 7, 10\)), the remainder \(2^{64} \pmod n\) leaves the lower buckets with one extra possibility than the upper buckets.

    Fair Pick Cutoff Formula

    \(L = 2^{64} - (2^{64} \pmod n)\)

    If \(V < L\), accept \(V \pmod n\).
    If \(V \ge L\), reject \(V\), re-hash \(V\) via SHA-256, and test the next candidate. This ensures every outcome in \([0, n-1]\) has identical probability.

    Note: This is an empirical demonstration comparing finite sample distributions; not a substitute for mathematical proofs.
